# Student Performance Prediction using Machine Learning

## Overview
This project aims to predict students' mathematics scores based on writing performance and daily routine habits using machine learning techniques.

## Problem Statement
Academic performance is influenced by multiple factors beyond classroom teaching. This project analyzes how daily habits and writing skills impact students' mathematics outcomes.

## Dataset
The dataset includes features such as:
- Writing scores
- Study habits / daily routine indicators
- Mathematics scores (target variable)

## Approach
- Data preprocessing and feature selection
- Train-test split for evaluation
- Regression-based machine learning model for prediction

## Tools & Technologies
- Python
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## Learning Outcome
Through this project, I gained hands-on experience in working with real-world educational data, model evaluation, and understanding the relationship between student habits and academic performance.
